# lin0dev

个人技术站。用来展示工程作品与技术笔记。

线上地址：https://lin0dev.tech

## 结构

`site/` 是全部源码，共 10 个文件，可直接部署：

```
site/
├── index.html          首页
├── 404.html            错误页
├── assets/style.css    全站样式
├── notes/              技术笔记
└── projects/           作品详情页
```

## 本地预览

不需要安装依赖，起一个静态服务器即可：

```bash
cd site
python -m http.server 8080
```

浏览器打开 http://localhost:8080 。

## 为什么不用框架

页面数量固定，内容以文本为主，没有客户端状态要管。引入构建链只会多一层故障面：多一份依赖、多一步构建、多一个可能失败的环境。用原生 HTML 加一份 CSS，改完直接上线，链路短到可以手工复核每一步。

这个取舍有代价：以后要加交互组件，得自己写或重新选型。现阶段内容形态还不需要，等到真需要时再引入，那时也知道该引入什么。

## 部署

静态文件由 Nginx 托管，HTTPS 在反向代理层终止。仓库只存页面源码，部署脚本、访问日志与数据文件不在其中。
